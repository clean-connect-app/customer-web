# Clean Connect для клиентов

Клиентский веб на React и Vite. Каталог и оформление перенесены из прототипа `p1`. В разделе «Мои заказы» клиент открывает карточку, проверяет статус и меняет заказ до назначения курьера.

## Локальный запуск

Сначала запустите API Clean Connect на `127.0.0.1:3000`. Используйте Node.js из `.nvmrc`.

```powershell
npm ci
npm run dev
```

Откройте `http://127.0.0.1:5173`. Для оформления и просмотра заказов настройте вход по email в API. Vite передаёт запросы `/api` серверу. В развёрнутой среде направьте этот путь на API и возвращайте `index.html` для маршрутов `/orders` и `/orders/:id`.

`npm run check` проверяет правила кода, форматирование и типы, затем собирает веб-приложение.
